# Asher's Story Quest: Complete Art Prompt Pack

This file covers every image the app could use, with ready-to-paste prompts for an image generator such as Midjourney, DALL·E, Ideogram, Leonardo or Firefly.

**How to use it**
1. Generate the **Ember character sheet (E-00)** first and choose the version you like best. Use it as a reference image (image prompt, "character reference," or "style reference") for every other piece, so Ember looks the same everywhere.
2. Then generate the **map (M-01)**. It sets the style for everything else.
3. Generate everything else in any order. Save each file with the **file name** listed so I can drop them straight into the app.
4. Send the images back to me in this chat, and I'll wire them into the app.

---

## 1. Global style guide (add to EVERY prompt)

Paste this **style block** at the end of each prompt:

> *Style: bright storybook fantasy game art for kids ages 8–11, bold clean shapes, thick dark-navy outlines (#1b1f3a), flat colors with soft cel shading and one light source from the top left, cheerful and adventurous rather than babyish, similar in spirit to a modern mobile adventure game, high detail but uncluttered, no text, no letters, no words, no logos, no watermark.*

**Negative prompt** (for generators that support one):

> *text, letters, words, watermark, signature, logo, realistic photo, gore, blood, scary realistic faces, weapons pointed at viewer, trademarked characters, Minecraft characters, Fortnite characters, Pokémon, Disney characters, blurry, low contrast, cluttered background*

**Color palette** (matches the app exactly):

| Name | Hex | Used for |
|---|---|---|
| Night blue (app background) | `#14286b` | Backgrounds, deep areas |
| Deep navy | `#0d1b4d` | Shadows, outlines |
| Ink | `#1b1f3a` | Outlines |
| Meadow green | `#2fa65a` | Apprentice Village (3rd grade) |
| Mountain violet | `#6c4bd8` | Dragon Mountains (4th grade) |
| Dragon red | `#ff5a3c` | Storm Castle (5th grade), bosses, Ember |
| Gold | `#ffc83d` | Rewards, stars, treasure |
| Soft blue-white | `#eef3ff` | Light panels |

**Content rules**
- **Original designs only.** Nothing that looks like Minecraft, Fortnite, Pokémon, How to Train Your Dragon or other brands. For the "Game Worlds" art, use generic *block-built worlds* and *storm islands* in an original style.
- **No text inside images.** The app adds all words itself, so they stay crisp and editable.
- **Kid-safe spooky only.** Ghosts are friendly or goofy, and nothing should be gory or truly frightening.
- **Transparent backgrounds** for anything marked **PNG-T**. If your generator can't make them, ask for a "plain solid white background" and remove it afterwards, for example with remove.bg or the iPad Photos "lift subject" feature.

**Sizes and formats key**
- **Wide 16:9:** 1920×1080
- **Map 3:2:** 1500×1000 (the app's map is 1000×680, so generate larger and crop)
- **Square:** 1024×1024
- **Banner 3:1:** 1800×600
- **PNG-T:** PNG with a transparent background
