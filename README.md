# Asher’s Story Quest — Complete Art Pack

110 distinct assets, each individually generated and reviewed, in the exact filenames from the supplied brief.

- `png/`: 110 PNGs at the brief’s requested export dimensions. Use these when the app expects the original `.png` filenames.
- `webp/`: the same 110 assets in smaller WebP files, all under 1 MB each. Change app extensions to `.webp` when using these.
- `index.html`: searchable visual gallery. Extract the ZIP first, then open this file in a browser.
- `previews/`: four labeled contact sheets.
- `asset-checklist.csv`: dimensions, transparency and file sizes.
- `asset-manifest.json`: asset details and generation prompts.

## Confirmed choices
Sleeping Ember uses curling smoke, with no Zs or letters. The front card frame has a transparent center for app content. The locked medal is entirely grayscale. All art is free of in-image wording; the app supplies editable text.

## Export details
Square files: 1024×1024. Banners: 1800×600. Wide art: 1920×1080. Map: 1500×1000. Cards: 1000×1500. Share thumbnail: 1200×630. Certificate: 3300×2550, tagged 300 DPI.

Generated raster images were resampled to the requested export dimensions. Some wide images and the certificate are enlarged from the generator’s native output; enlargement does not add native detail. Native dimensions are recorded in the checklist. PNGs preserve full color and may exceed 1 MB; the WebP copies meet the brief’s loading-size target.

All imagery was created using the built-in image generator, with the Ember turnaround as a recurring reference. The five tab icons and locked badge were corrected during review. These are static illustrations; loading art and wheels require app animation if desired. No app source was included, so integration is not part of this archive.
